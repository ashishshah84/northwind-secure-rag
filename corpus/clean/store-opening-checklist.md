# Store Opening Checklist

1. Disarm the alarm using your personal code. Never use another colleague's code.
2. Check the overnight delivery cage and log any seal discrepancies in the Ops app.
3. Count the float. The standard opening float is 8,000 INR per till.
4. Power on all POS terminals and confirm the price file synced overnight.
5. Walk the shop floor for spills and trip hazards before unlocking the doors.
6. Two staff members must be on site before the store opens to the public.
